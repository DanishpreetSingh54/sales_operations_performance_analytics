# Sales Operations & Performance Analytics

An end-to-end analytics project that turns raw sales operations data into actionable business insights — covering data cleaning, SQL-based analysis, and an interactive Power BI dashboard.

## 📌 Project Overview

This project analyzes sales operations data to uncover trends in performance, efficiency, and revenue drivers. It covers the full analytics pipeline: raw data → cleaned data → SQL analysis → notebook-based exploration → Power BI dashboard for business reporting.

The goal is to simulate a real-world business analytics workflow — the kind used by sales operations and business intelligence teams to monitor performance and guide strategic decisions.

## 🎯 Business Questions Explored

- Which products/regions/teams drive the most sales performance?
- Where are the biggest operational inefficiencies?
- What trends emerge over time in sales volume and revenue?
- How do sales metrics vary across time periods, categories, or segments?
- How can these insights support better operational decisions?

## 🔍 Approach

1. **Data Cleaning** – Raw sales operations data is cleaned and structured for analysis.
2. **SQL Analysis** – Structured queries extract KPIs such as total sales, growth trends, regional performance, and efficiency metrics.
3. **Exploratory Analysis** – Jupyter notebooks are used to explore patterns, validate SQL findings, and visualize distributions.
4. **Dashboarding** – Key metrics and insights are consolidated into an interactive Power BI dashboard for easy business reporting.

## 🛠️ Tools & Technologies

- **SQL** – data querying and aggregation
- **Python (Jupyter Notebook)** – data cleaning and exploratory analysis
- **Power BI** – interactive dashboard for visualizing key metrics
- **Git/GitHub** – version control and project hosting

## 📊 Dashboard

An interactive Power BI dashboard visualizes key sales operations metrics — including performance trends, regional breakdowns, and efficiency indicators — enabling quick, data-driven decision-making. It brings together the SQL and notebook analysis into a single, easy-to-read business view.

## 💡 Key Skills Demonstrated

- Data cleaning and preprocessing
- SQL querying for business analytics (aggregation, filtering, joins)
- Exploratory data analysis using Python
- Dashboard design and data storytelling with Power BI
- End-to-end analytics project structuring

## 🚀 How to Use

1. Clone the repository
2. Explore the raw/processed data in `data/`
3. Run the SQL scripts in `sql/` against your database
4. Open the notebooks in `notebooks/` to see the analysis workflow
5. Open the `.pbix` file in `power_bi/` using Power BI Desktop to view the dashboard
